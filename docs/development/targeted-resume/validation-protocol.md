# 岗位定制简历：探索验证记录

状态：尚未招募或执行。此文件是后续 T7 的记录模板，不是用户研究结果。

对象：5～8 位有真实项目、实习或工作经历的技术求职者。只使用本人自愿提供、允许在其配置模型上处理的材料；记录中去掉姓名、联系方式、公司内部信息。材料和真实简历不提交仓库。

## 每位参与者的流程

1. 选择两个职责侧重点不同、本人有意投递的 JD。
2. 记录原有整理方式：材料来源、用时、主要困难、原有简历。
3. 使用产品完成第一个岗位稿：记录输入、补问、审阅、编辑、导出及中断点。
4. 复用材料完成第二个岗位稿：观察是否重复填写、重点变化是否合理。
5. 请参与者指出每条建议的采纳、修改或删除原因；对照原材料排查新增事实、职责升级和口径错位。
6. 询问是否确认可投递，以及仍需哪些修改；用户不愿投递也应记录原因。
